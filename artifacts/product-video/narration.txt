AI agents are becoming powerful, but a skill file can quietly change what an agent may read, reveal, or do. SkillTrustOps turns that uncertainty into evidence before the skill ships.

Start with one SKILL.md. The Overview gives the team a simple trust workflow: select the skill, inspect its behavior, apply policy gates, and explain the decision.

Static inspection checks structure, dangerous instructions, secrets, and sensitive data locally. Submitted code is not executed.

For behavioral testing, choose the model and sandbox from repository policy. SkillTrustOps creates synthetic records, safe canaries, and in-memory fake tools. It then runs direct and indirect prompt injection, disclosure, unauthorized action, confirmation bypass, and multi-turn attacks.

The sandbox must exit before model attacks begin. Packages are mounted read-only, networking is disabled, privileges are dropped, and resource limits are recorded.

Here, all six attacks were resisted and Docker isolation passed. SkillTrustOps still reports inconclusive, because Docker is development isolation. Assurance requires the stronger gVisor boundary with a digest-pinned image. The product never turns missing proof into a pass.

When an attack succeeds, the Findings view explains what happened, why it matters, how to fix it, and maps the evidence to OWASP and MITRE ATLAS.

The same policy runs on a laptop, in CI, or behind any agent framework. Every assessment produces a plain-English report, machine-readable evidence, event logs, and integrity hashes.

SkillTrustOps is the trust gate for agent skills: test safely, explain clearly, and ship only what you can prove.
