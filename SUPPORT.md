# Support policy

GitHub Issues is the public support channel. Include the SkillTrustOps version,
Python version, operating system, command, policy hash, and a minimized synthetic
reproducer. Remove secrets, personal data, absolute home paths, and live-model
transcripts before posting.

The `0.x` line is a preview with no uptime or response-time SLA. Enterprise
support, compliance certification, and model-safety guarantees are not offered.
Security reports follow `SECURITY.md`, not the public issue tracker.
